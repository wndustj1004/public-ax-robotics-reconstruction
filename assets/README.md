# assets

이 폴더는 비어 있다.

시연 사진·영상, 촬영한 판별 대상 이미지, LCD 화면 캡처는 넣지 않았다.

- 실습 환경에서 촬영한 자료의 공개·재사용 허가를 확인하지 못했다.
- 사람이 찍힌 컷이 섞여 있어 공개 저장소에 올리기에 적절하지 않다.

당시 활동을 확인할 수 있는 자료는 이 저장소가 아니라 별도 제출본
(수료증, 기획서, 발표자료, 시연 영상 캡처)으로 제시한다.

`.gitignore` 가 이미지·영상 확장자를 막고 있으므로, 여기에 파일을 넣어도
실수로 커밋되지 않는다. 의도해서 넣으려면 `.gitignore` 를 먼저 고쳐야 한다.
