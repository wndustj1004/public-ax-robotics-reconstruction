# 수업자료 참조 범위

## 원칙

부트캠프 수업자료(PDF 12종, 실습 노트북 3종)는 **공개·재사용 허가를 확인할 수 없어
이 저장소에 포함하지 않았다.** 원문 복사도 하지 않았다.

여기 적는 것은 "어떤 주제를 배웠고, 그중 무엇이 이 저장소의 어떤 설계로 이어졌는가"뿐이다.

## 배운 주제와 이 저장소의 관계

| 수업 주제 | 이 저장소에 반영된 것 | 코드를 가져왔나 |
|---|---|---|
| 객체 인식과 라벨링 | 3클래스 데이터셋 스키마의 형식 (`training/dataset_schema.yaml`) | 아니오. 형식은 ultralytics 공개 규격 |
| 모델 학습 및 추론 | 학습 절차의 골격 (`training/train_example.py`) | 아니오. ultralytics 공개 API 호출만 |
| 카메라 센서 기초 | 마커 거리 기반 정차라는 요구사항 | 아니오 |
| 라인트레이싱 | **반영하지 않음.** 작성자가 담당하지 않은 영역 | 아니오 |
| LCD 표시 | 상태 표시를 `Notifier` 프로토콜로 추상화 | 아니오. 구현은 없음 |
| Physical AI · 모방학습 | **반영하지 않음.** 작성자가 담당하지 않은 영역 | 아니오 |

## 팀 코드와의 관계

폴더에 남아 있는 팀 코드(이전 세대 주행 노트북, HMI 스크립트)도 저장소에 넣지 않았다.
본인 저작물이 아니고 공개 동의를 받지 않았다.

다만 **문서로 인용한 사실**은 있다. 재현 가능성을 위해 어떤 값이 어디서 왔는지 적는다.

| 값 | 출처 | 비고 |
|---|---|---|
| `min_confidence: 0.70` | 이전 세대 팀 노트북의 `YOLO_CONF` | 최종본 값은 확인 불가 |
| 마커 ID 불일치 (0 vs 1) | 이전 세대 노트북은 `ROBOT_ARUCO_ID = 1` | 최종본 기준 0으로 확정 |
| 클래스 문자열 불일치 | 이전 세대 노트북은 `robot_fix` / `human_fix` | 문서 표기는 `robotfix` / `humanfix` |
| 교체 대기 최대 120초 | 팀 HMI 스크립트의 알림 정의 | 설정값으로 옮김 |

## 외부 라이브러리

| 라이브러리 | 라이선스 | 용도 |
|---|---|---|
| PyYAML | MIT | 설정 로드 |
| pytest | MIT | 테스트 |
| ultralytics (선택) | AGPL-3.0 | 실제 학습·추론 시에만. **이 저장소는 의존하지 않는다** |

> `ultralytics` 는 AGPL-3.0 이다. 이 저장소는 해당 패키지를 포함하지 않고
> `requirements.txt` 에서도 주석 처리해 두었다. 실제 학습·추론에 사용할 때는
> 사용자가 라이선스 조건을 직접 확인해야 한다.
